# PSI-Projekt-zaliczeniowy-2026

Projekt dotyczy analizy wierszy poprzez analizę częstości słów i analizę sentymentu

Grupa: Jakub Rutkowski, Mikołaj Wojtkowski, Marek Grajewski

Podział obowiązków:

Jakub Rutkowski - Przygotowanie danych tekstowych, czyszczenie, stemming i analiza częstości słów

Mikołaj Wojtkowski - Analiza sentymentu i przygotowanie raportu HTML

Marek Grajewski - Opracowanie dokumentacji SRS
